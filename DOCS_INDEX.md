# Docs Index

## Purpose
This folder-level index links the core product documents for Foody in the order they are usually read and used.

## Recommended Reading Order
1. [PRD](PRD.md)
2. [Technical Architecture](TECHNICAL_ARCHITECTURE.md)
3. [Security & Access](SECURITY_ACCESS.md)
4. [Frontend Spec](FRONTEND_SPEC.md)
5. [Feature Tickets](FEATURE_TICKETS.md)

## What Each Doc Is For
### PRD
Defines the product, users, goals, scope, and launch boundaries.

### Technical Architecture
Defines the stack, folder structure, data model, and environment setup.

### Security & Access
Defines authentication, roles, permissions, error handling, and edge cases.

### Frontend Spec
Defines the design system, UI rules, and external integrations.

### Feature Tickets
Breaks the product into buildable tasks with dependencies and priorities.

## Notes
Keep these documents aligned as the product changes. If one of them changes in a way that affects the others, update the related docs at the same time.
